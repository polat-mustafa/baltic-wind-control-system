# Baltic Wind HV Control Platform

English documentation for the 510 MW Baltic Sea offshore wind farm simulation. This track now contains the full English lesson sequence used for GitHub Pages publication, together with the user guide and the core project references.

## What Is Included

- platform overview and reading order,
- user guide for local setup and daily workflow,
- complete English lesson track `000`-`018`,
- links back to the main engineering standards and roadmap documents.

## Recommended Reading Order

1. Start with [User Guide](user-guide.md) if you want to run the project.
2. Read [Lessons Overview](lessons/index.md) for the full learning sequence.
3. Use [SKILL.md](../SKILL.md), [Project Roadmap](../Project_Roadmap.md), and [Learning Roadmap](../Learning_Roadmap.md) as authoritative references.

## Reference Plant

34 x Vestas V236-15.0 MW | 66 kV array | 220 kV export over 45 km | 400 kV PSE connection | +/-120 MVAR STATCOM + 50 MVAR shunt reactor
