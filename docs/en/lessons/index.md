# Lessons Overview - Baltic Wind HV Control Platform

<a id="the-project-at-a-glance"></a>
## The Project at a Glance

This section contains the full English lesson track for the Baltic Wind HV Control Platform. Lessons `000` and `001` are original English foundation lessons, and lessons `002`-`018` are direct-authored English translations of the Turkish engineering lesson set.

<a id="system-architecture"></a>
## System Architecture

The lesson track follows the same five-part engineering architecture as the repository:

- P1: wind resource and AEP,
- P2: HV grid integration,
- P3: SCADA and automation,
- P4: AI forecasting,
- P5: commissioning and protection readiness.

<a id="document-philosophy-iec-61355"></a>
## Document Philosophy (IEC 61355)

Lessons are treated as controlled engineering records. They are written to preserve the chain from requirement and physical principle to implementation.

<a id="session-protocol"></a>
## Session Protocol

Each lesson is intended to support the project teaching pattern: physics, standard, maths, and code.

---

## How to Read the Track

1. Start with `000`-`001` for project method and DevOps foundations.
2. Read `002`-`006` for multilingual workflow and wind-resource engineering.
3. Read `007`-`008` for steady-state and dynamic grid integration.
4. Read `009`-`012` for IEC 61850, SCADA workflow, cybersecurity, and data quality.
5. Read `013`-`016` for probabilistic forecasting and model evaluation.
6. Read `017`-`018` for commissioning, acceptance testing, and protection coordination.
