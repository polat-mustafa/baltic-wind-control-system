# Baltic Wind HV Control Platform - Polski Tor Dokumentacji

Polska dokumentacja dla symulacji morskiej farmy wiatrowej 510 MW na Morzu Baltyckim. Ten tor zawiera polskie tlumaczenia tureckich lekcji inzynierskich, przewodnik uzytkownika oraz odniesienia do glownej dokumentacji projektu.

## Co Zawiera Ten Tor

- polski punkt wejscia do dokumentacji publikowanej w GitHub Pages,
- przewodnik uzytkownika,
- polskie tlumaczenia lekcji `002`-`018`,
- odwolania do glownych dokumentow projektowych i standardow.

## Zalecana Kolejnosc Czytania

1. Zacznij od [Przewodnika uzytkownika](przewodnik-uzytkownika.md), jesli chcesz uruchomic projekt lokalnie.
2. Przejdz do [Przegladu lekcji](lessons/index.md), aby zobaczyc caly ciag nauki.
3. Korzystaj z [SKILL.md](../SKILL.md), [Project Roadmap](../Project_Roadmap.md) i [Learning Roadmap](../Learning_Roadmap.md) jako glownych referencji.

## Elektrownia Referencyjna

34 x Vestas V236-15.0 MW | system zbiorczy 66 kV | eksport 220 kV na 45 km | przylaczenie 400 kV PSE | +/-120 MVAR STATCOM + reaktor 50 MVAR
